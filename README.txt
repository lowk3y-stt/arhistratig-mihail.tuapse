САЙТ ХРАМА АРХАНГЕЛА МИХАИЛА В ТУАПСЕ
СБОРКА 1.4.0

КАК ОТКРЫТЬ
Откройте файл index.html двойным щелчком. Чтобы выложить сайт в интернет,
загрузите всю папку на хостинг целиком. Папки css, js и img должны лежать
рядом со страницами.

СТРАНИЦЫ
index.html     Главная: новости, о приходе, разделы
services.html  Расписание богослужений
treby.html     Требы и таинства
feasts.html    Праздники
school.html    Воскресная школа
youth.html     Молодёжное движение
photos.html    Фотографии
contacts.html  Контакты

КАК ДОБАВИТЬ НОВОСТЬ
1. Откройте index.html в любом текстовом редакторе (Блокнот подойдёт).
2. Найдите комментарий «НОВОСТИ» и блок <article class="frame news-item"> под ним.
3. Скопируйте блок целиком и вставьте перед ним: свежая новость идёт первой.
4. Замените дату, заголовок и текст. Фото положите в папку img и укажите
   его имя в двух местах блока (href и src).

КАК ОБНОВИТЬ РАСПИСАНИЕ
Расписание лежит в services.html. Оно записано дважды: таблица для планшетов
и компьютеров и карточки для телефонов. Правьте оба места. Проще всего
прислать новое расписание фотографией, и его перенесут в таблицу.


ДОПОЛНЕНИЕ
- Расписание само скрывает прошедшее по московскому времени. Служба исчезает через GRACE_HOURS (по умолчанию 2) часа после начала. Число меняется в начале блока про расписание в js/script.js.
- Данные расписания лежат в блоке <script id="sched-data"> в services.html (и копия в index.html для блока «Ближайшая служба»). Новое расписание проще всего прислать Claude, он пересоберёт сайт.
- Значок ВКонтакте: файл img/vk.png. Чтобы заменить, положите другой файл с тем же именем.
- Часы работы храма и лавки: блок class="hours" в index.html.

ФОТОГРАФИИ МОЛОДЁЖИ
Карусель на странице youth.html и сетка на photos.html собираются из файлов img/yp-01.webp ... yp-16.webp (полный размер) и yp-01-t.webp ... (уменьшенные для сетки). Телефон куратора и текст страницы молодёжи лежат в youth.html.

ПРЕСТОЛЬНЫЙ ПРАЗДНИК
С 20 по 22 ноября (по московскому времени) на всех страницах сам появляется
праздничный баннер «С праздником Собора Архистратига Михаила!». Чтобы посмотреть
его в любой день, добавьте к адресу страницы ?prestol (например index.html?prestol).
Даты меняются в самом конце файла js/script.js (строка со словом «ноября»/d.d >= 20).
